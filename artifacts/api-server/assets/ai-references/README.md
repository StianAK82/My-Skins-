# Optional AI quality references

Place up to three project-owned or appropriately licensed PNG files in `shirt/`
or `pants/`. Files are loaded alphabetically. They are sent after the blank atlas
and region guide and are used only to communicate fabric detail and believable
construction quality—not colours, graphics, text, logos, or exact designs.

Do not place Roblox Marketplace artwork here without the copyright holder's
permission. Generation works normally when these directories are empty. The
root can be overridden with `AI_QUALITY_REFERENCES_DIR`.
