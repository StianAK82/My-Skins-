# Asset router

`ASSET_REGISTRY` and `routeAsset` provide deterministic exact-kind resolution for 28 prioritized garment/accessory kinds. Entries declare variants, fit/size coverage, preview and Classic implementations, the absence of production 3D, evidence, fallback, limitations, rights, version, and tests. Missing or incompatible entries return `unsupported`; they are never silently mapped to a hoodie.
