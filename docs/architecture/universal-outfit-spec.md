# UniversalOutfitSpec 1.0

The strict Zod schema in `artifacts/api-server/src/lib/universal-outfit.ts` records generation/language/intent/style/palette, stable item IDs, relationships, fit, silhouette, material, details, size, placement, layers, capabilities, honest fallback/unsupported states, safety/rights/moderation, hashed revision history, validation evidence, fifteen quality dimensions and repair history. Duplicate IDs, dangling relationships, and simultaneous supported one-piece plus top/bottom garments are rejected.
