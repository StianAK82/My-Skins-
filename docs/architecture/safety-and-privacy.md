# Safety and privacy

SafetyGateway runs before every AI route and covers prompt length, rate limiting, PII, sexual content, extreme violence, hate/extremism, self-harm, drugs, protected characters and brand/logo requests. It rewrites certain character requests into disclosed original inspiration and blocks logo copying. Diagnostics use hashes/categories; generated images are moderated fail-closed. Retention helpers and tests cover expiry. Lawful consent is required before any evaluation export is used for training.
